# Othello AI - Boblise

This project implements an Othello AI called "Boblise" using Heuristic-Alpha-Beta-Search.

## Compilation

If you make any changes to the source code, recompile the AI using:

```bash
javac ./OthelloAIBoblise.java
```

## Running the AI

Boblise should be run as player 2 (white)

```bash
java Othello DumAI OthelloAIBoblise  
```
